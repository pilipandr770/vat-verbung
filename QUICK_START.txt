❓ TROUBLESHOOTING:

Q: "System check failed"
A: Run 'python system_check.py' to see what's wrong
   Most common: Missing .env file or credentials not filled

Q: "Database connection refused"
A: Check DATABASE_URL in .env
   Ensure PostgreSQL is running

Q: "Instagram session expired"
A: Run 'python init_instagram.py'

Q: "ModuleNotFoundError: No module named 'X'"
A: Run 'pip install -r requirements.txt'

Q: "Port already in use"
A: Check if another instance is running
   Kill with: pkill -f "python main.py"

Check logs for errors:
  $ grep ERROR logs/promotion_hub.log
