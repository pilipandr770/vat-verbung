## 🔧 CONFIGURATION EXAMPLE

### In Your .env File:

```dotenv
# ═══════════════════════════════════════════════════════
# WORK HOURS (Day/Night Mode)
# ═══════════════════════════════════════════════════════

# Start invitations and publications at 9 AM
WORK_HOURS_START=9

# Stop invitations and publications at 6 PM (18:00)
WORK_HOURS_END=18

# Your timezone
TIMEZONE=Europe/Berlin

# Enable the feature
WORK_HOURS_ENABLED=True

# ═══════════════════════════════════════════════════════
# INVITATIONS
# ═══════════════════════════════════════════════════════

# Wait 3-5 minutes between invites (180-300 seconds)
INVITATION_DELAY_MIN=180
INVITATION_DELAY_MAX=300

# Use random messages instead of repeated ones
USE_RANDOM_MESSAGES=True

# How many variants per message type
MESSAGE_TEMPLATE_VARIANTS=5
```

### What This Means:

```
✅ 09:00 - Invitations START
   └─ Send first batch
   └─ Wait 3-5 minutes
   └─ Send second batch
   └─ Repeat...

✅ 18:00 - Invitations STOP
   └─ No invitations after 6 PM
   └─ No publications after 6 PM
   └─ Silent until 09:00 tomorrow

✅ Uses 5 different messages
   └─ Message 1, Message 2, Message 3...
   └─ No repetition
   └─ Personalized
   └─ Natural-looking

✅ Everything randomized
   └─ Which message? Random
   └─ When to wait? Random (3-5 min)
   └─ No patterns
   └─ No bot detection
```
