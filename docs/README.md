# Документація

Це папка з документацією проєкту.

## Файли

- **README.md** — огляд проєкту
- **ARCHITECTURE.md** — архітектура та дизайн
- **CHANNELS.md** — деталі роботи каналів
- **CONTENT_STRATEGY.md** — контент-стратегія (німецька, B2B)
- **RULES.md** — антиспам-правила та філософія
- **HOW_TO_RUN.md** — як запустити проєкт

Кожен файл написаний для людей (Copilot Agent) й мав би дати відповідь на типові запитання.
